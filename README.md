## ✨ About The Project

TMWFile is a sleek and modern web application built exclusively for exploring a vast catalog of movies and television series. This project was developed as an educational endeavor to explore modern web design, API integration, and AI-assisted coding.

**⚠️ Disclaimer:** This application is for **Private and Personal use only**. It is created purely for educational purposes to demonstrate web development skills and API consumption.

## 🚀 Features

- **Extensive Catalog:** Browse through an endless collection of Movies, TV Series, and Shows.
- **Beautiful UI:** A dynamic and responsive user interface designed for a premium user experience.
- **AI-Powered Development:** Built with the assistance of Google's Gemini AI, accelerating the development process and enhancing code quality.
- **Real-Time Data:** Integrates seamlessly with a Free Movie Database API to fetch up-to-date information, posters, and details.

## 🛠️ Built With

- HTML5 / CSS3 / Vanilla JavaScript
- **AI Assistant:** Google Gemini AI
- **Data Source:** Free Movie Database API

## 📝 Usage

Simply open the application in your browser to start exploring titles. Search for your favorite movies or discover new trending series.

> **Note:** As this project relies on a free API tier, please be mindful of rate limits during heavy usage.
